# WishBloom 🌸

A warm, playful birthday-wish experience by **Shivaayu**.

## V7.1 polish update
- Mobile-friendly creator navigation and creator credit placement.
- Fixed creator-form **Back** navigation.
- Added a safer Continue flow that prevents accidental double-taps while photos are being processed.
- Reworked photo cropping to a simple **1:1 square** editor.
  - Drag the image directly inside the square.
  - Use **+ / −** to zoom.
  - No separate X/Y/zoom sliders.
- Recipient photos remain square for a consistent, profile-picture-style presentation.
- Existing music, sound controls, language modes, games, wishes, credits and sharing flow are preserved.
